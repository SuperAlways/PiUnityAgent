## 每篇的结构

1. **它解决什么问题**（不用术语堆砌）
2. **数据流 / 状态机**（一张图或时序）
3. **三条关键不变量**
4. **失败模式**（网络/超时/中止/坏参数/空结果）
5. **TS 与 C# 的差异**（为什么这样映射）
6. **调优旋钮**（影响、默认、什么时候调）
7. **小练习**（用来验证"真的懂了"）

## 写作纪律

- 不抄书、不翻译；只写"我们自己的理解"。
- 讲不清的设计不写进文档，也不写进代码。
- 每次用户提问/纠正，追加到 `Q&A.md`，不要只留在聊天记录里。
- 代码变更时同步更新对应篇章；过期内容标注日期。
