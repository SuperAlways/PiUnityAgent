# S1 消息与内容模型 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 S1 spec 重建 `PiUnityAgent.Ai` 的消息/内容模型，使 wire 形状贴 pi（原版）、C# 形状贴 pi.net，并通过 14+ 单测与 Release 门禁。

**Architecture:** `PiUnityAgent.Ai` 的 `Types/` 只放纯数据与校验；`MessageContent` 包装 `string | blocks`；`ContentBlock` 用 `JsonPolymorphic` + `JsonIgnore Type`；枚举用自定义 converter；消息用 init 属性 + `required`；可选类型保留、实现后置。

**Tech Stack:** C# / netstandard2.1 / System.Text.Json 8.0.5 / xUnit（测试 net10.0）。

## Global Constraints

- 库目标框架：`netstandard2.1`；测试：`net10.0`。
- 禁止引用 `UnityEngine` / `GameData.*` / Harmony。
- 禁止 .NET 9 专有 API（`JsonStringEnumMemberName`、`Lock`、`Task.WhenEach` 等）。
- 公共类型名贴 pi（原版）：`ToolCall`（不是 `ToolCallContent`）、`ThinkingSignature`（不是 `Signature`）。
- wire `type` 判别符：`text` / `thinking` / `image` / `toolCall`。
- 提交时显式 `git add`，禁止 `git add -A`。
- 当前 S1 草稿 tag：`s1-draft-2026-11-05`；返工在分支 `rework/s1` 上进行。

```csharp
using System;
using System.Text.Json;
using System.Text.Json.Serialization;

namespace PiUnityAgent.Ai.Types;

[JsonConverter(typeof(MessageContentJsonConverter))]
public abstract record MessageContent
{
    public sealed record Text(string Value) : MessageContent;

    public sealed record Blocks(IReadOnlyList<ContentBlock> Value) : MessageContent;

    public static MessageContent From(string text) => new Text(text);

    public static MessageContent From(IReadOnlyList<ContentBlock> blocks) => new Blocks(blocks);

    public IReadOnlyList<ContentBlock> ToBlocks() => this switch
    {
        Text text => new ContentBlock[] { new TextContent { Text = text.Value } },
        Blocks blocks => blocks.Value,
        _ => throw new InvalidOperationException($"Unsupported MessageContent variant: {GetType().Name}")
    };
}

public sealed class MessageContentJsonConverter : JsonConverter<MessageContent>
{
    public override bool HandleNull => true;

    public override MessageContent Read(
        ref Utf8JsonReader reader, Type typeToConvert, JsonSerializerOptions options)
        => reader.TokenType switch
        {
            JsonTokenType.String => new MessageContent.Text(reader.GetString()!),
            JsonTokenType.StartArray => new MessageContent.Blocks(
                JsonSerializer.Deserialize<List<ContentBlock>>(ref reader, options) ?? new()),
            JsonTokenType.Null => new MessageContent.Blocks(Array.Empty<ContentBlock>()),
            _ => throw new JsonException(
                $"MessageContent expects a string or an array, got {reader.TokenType}.")
        };

    public override void Write(
        Utf8JsonWriter writer, MessageContent value, JsonSerializerOptions options)
    {
        switch (value)
        {
            case null:
                writer.WriteStringValue("");
                break;
            case MessageContent.Text text:
                writer.WriteStringValue(text.Value);
                break;
            case MessageContent.Blocks blocks:
                JsonSerializer.Serialize(writer, blocks.Value, options);
                break;
            default:
                throw new JsonException($"Unsupported MessageContent variant: {value.GetType().Name}");
        }
    }
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

namespace PiUnityAgent.Ai.Types;

public static class MessageValidation
{
    public static void Validate(Message message)
    {
        switch (message)
        {
            case SystemMessage system:
                RequireBlocks(system.Content.ToBlocks(), nameof(SystemMessage), b => b is TextContent);
                break;
            case UserMessage user:
                RequireBlocks(user.Content.ToBlocks(), nameof(UserMessage), b => b is TextContent || b is ImageContent);
                break;
            case AssistantMessage assistant:
                RequireBlocks(assistant.Content, nameof(AssistantMessage),
                    b => b is TextContent || b is ThinkingContent || b is ToolCall);
                break;
            case ToolResultMessage result:
                if (string.IsNullOrEmpty(result.ToolCallId))
                    throw new ArgumentException("ToolResultMessage.ToolCallId must reference a ToolCall.", nameof(message));
                RequireBlocks(result.Content, nameof(ToolResultMessage), b => b is TextContent || b is ImageContent);
                break;
            default:
                throw new ArgumentException($"Unknown message type: {message.GetType().Name}.", nameof(message));
        }
    }

    public static void ValidateToolPair(AssistantMessage assistant, ToolResultMessage result)
    {
        if (!assistant.Content.OfType<ToolCall>().Any(call => call.Id == result.ToolCallId))
            throw new InvalidOperationException(
                $"ToolResultMessage.ToolCallId '{result.ToolCallId}' does not match any ToolCall in the assistant message.");
    }

    private static void RequireBlocks(
        IReadOnlyList<ContentBlock> blocks, string owner, Func<ContentBlock, bool> allowed)
    {
        foreach (var block in blocks)
        {
            if (!allowed(block))
                throw new ArgumentException($"{owner} contains unsupported content block: {block.Type}.");
        }
    }
}
```
