## 六、设计边界（强制）

1. `Ai/Core/Runtime` **禁止**引用 `UnityEngine` / `GameData.*` / `Harmony` / 任何游戏 DLL。
2. `Hosts.*` 只做适配、线程、传输、加载，**禁止业务判断**。
3. 扩展只引用 `Core/Runtime` 的接口，不直接引用 Hosts。
4. 游戏更新时只改 Hosts / 游戏适配器；`Ai/Core/Runtime` 与扩展零改动。
5. `Ai/Core/Runtime` 的新增逻辑必须配单测；Hosts 靠契约 + 实机。
