## 0. 背景

S3 v2 的代码、单测、门禁均通过，但偏离审查发现：

- **Auth 类型面**被简化成 `Credential`-based 的自定义形状，缺 `ModelAuth`/`Env`、`CredentialStore.modify/list`、`AuthContext.fileExists`、`ApiKeyAuth.check/login`、`OAuthAuth.toAuth` 等；这些不是 A 类强制，也不是 C 类允许的形状裁剪。
- **Models/Provider 门面**缺 `ModelsError`/`ModelsErrorCode`、`FilterAllModels`、`transformHeaders`、`LazyStreamObserver`、`CreateModelsOptions` 的 `modelsStore/identity`、`StaticProvider` 的 api-map 分派；`IProvider.Auth` 可空及“null=已配置”是发明语义。
- **Options/Faux** 有少量未登记的 extra/放宽：`StreamOptions.BaseUrl/StopSequences`、`ThinkingLevel` 命名与值域、Faux `inputLimits`、`ModelsStore` 删除不可表达等。
- 审计确认 Fetch 端口、LazyStream 语义、wire 枚举、Ai 边界、Dn 台账本身无问题。

本 spec 只补齐**公共形状**与必要的 API-key 行为；OAuth、动态目录、Deferred、图片/分类等仍按 Dn 后置。

### 0.1 v3.1 审视收口（2026-11-08）

在 v3 原稿上追加以下修正；全部为**公共形状/API-key 路径正确性**，不扩大 S4/S5 行为：

- `CredentialStore.ModifyAsync`：`null` = 保持不变（不是删除），返回写后凭据；按 provider `SemaphoreSlim` 串行化，不在 `lock` 内阻塞异步回调。
- `Models` Auth 解析：stored credential owns provider；stored OAuth 不被 ambient API key 顶掉；stored 类型无匹配返回 `null`，不静默回落；`overrides.ApiKey` 走 provider `Resolve` 且携带 `Env`。
- `AuthCheck.Type` 必填；`OAuthCredential.RefreshToken/ExpiresAt` 必填。
- `GetAuth(model)` 合并 `model.Headers`；`Models.Stream` 使用它，而不是只看 provider。
- `Identity` 逐字段合并；`ClientIdentity` 改为 pi 的 `UserAgentMode/ClientAttribution/Version` 形状。
- `ProviderFactory` 的 Images/Classifiers 必须落到 `IImagesProvider`/`IClassifierProvider`；`ProviderStreams.StreamSimple` 用独立的 `SimpleStreamFn`；新增 `ImagesOptions`/`ClassifierOptions` 形状。
- `LazyStreamObserver` 顺序按 pi：先 `Push` 再 `OnEvent`，先 `End` 再 `OnResult`；setup 失败 `OnResult(errorMessage)`。
- `FilterAllModels` fallback 保持原顺序，按 chat id 过滤，不重排。
- Auth 错误统一包 `ModelsError(Auth/OAuth)`；`LogoutAsync` 存储错误同样包 `ModelsError(Auth)`。

## 1. 目标 / 非目标

### 1.1 目标

- 按 pi/pi.net 补齐 Auth 公共形状；API Key 行为按新形状工作，并修正 stored-credential / override / ambient 的解析顺序。
- 补齐 ModelsError、FilterAllModels、transformHeaders、LazyStreamObserver、CreateModelsOptions、ProviderFactory/api-map 分派。
- 补 `ClientIdentity` 的 pi 形状（`UserAgentMode`/`ClientAttribution`/`Version`），删除自造 `Headers` 字段。
- 补 `ImagesOptions`/`ClassifierOptions` 与独立 `SimpleStreamFn`，让 `ProviderImages`/`ProviderClassifier`/`ProviderStreams` 不拿 `StreamOptions` 顶替。
- 修正 `IProvider.Auth`/Faux auth、ModelsStore、Options、Faux 输入限制等 shape/语义缺口；`GetAuth(model)` 合并模型头。
- 新增 pi 公共工具函数（cost/thinking/equality/api 判定）。
- 现有 201 测试全部适配；新增偏离补齐测试；Release 0/0。
- 更新 spec §6 三方偏离表、Dn 台账、教学篇、审计报告；复核审计 PASS。

### 1.2 非目标

- OAuth 登录/刷新/登出行为（D1/S5）。
- 动态目录刷新行为（D2/S4）。
- Deferred / 图片 / 分类真实实现（D3/D4/D5）。
- Prompt cache 行为（D6）、Telemetry 行为（D8）。
- 真实 OpenAI/Anthropic provider、Fetch 适配器、Unity 通信。
- 不扩展 Fetch 端口形状；不改 `UnityLlmTransport`。

## 2. 核心决策

| # | 决策 |
|---|---|
| D1 | **Auth 形状以 pi/pi.net 为准**；不再用 `(Credential, Source)` 简化 `AuthResult`。API Key 行为实现，OAuth 行为仍 C/D1。 |
| D2 | **`IProvider.Auth` 改为非空**（pi `Provider.auth` 必需）；Faux 也提供 keyless `ApiKeyAuth`。Models 不再把 `Auth==null` 当作“已配置”。 |
| D3 | **错误分类**：新增 `ModelsError`/`ModelsErrorCode`；auth、stream factory、Logout、流式 setup 的 RequireProvider 都使用它（审计后修复：RequireProvider 抛 `ModelsError(Provider, "Unknown provider: ...")`，与 pi/pi.net 一致，见 §4.1）。 |

| D8 | **ModelsStore 完整形状**：entry=models/lastModified/checkedAt/etag；store=read/write/delete；publication 增加删除语义。 |

| D10 | **pi 公共工具函数**：`calculateCost`/`getSupportedThinkingLevels`/`clampThinkingLevel`/`modelsAreEqual`/`hasApi`/`isModelType` 落到 `ModelOperations`。 |
| D11 | **Faux 补齐**：Faux auth（keyless）、`FauxModelDefinition.InputLimits`、状态字段按 D3 扩展；确定性保持。 |
| D12 | **验收门禁**：偏离补齐后必须由新的独立 subagent 重新审计，报告结论 PASS；否则不合并/不交付。 |
| D13 | **Auth 解析语义**：stored credential owns provider；显式 `ApiKey` 只在 provider 有 `ApiKey` 时走 `Resolve`（合成凭据带 `Env`）；stored 类型无匹配返回 null，不回落 ambient；错误统一 `ModelsError(Auth/OAuth)`。 |

| D15 | **身份形状**：`ClientIdentity` 采用 pi 的 `UserAgentMode`/`ClientAttribution`/`Version`/`AttributionSet`，`Models` 用 `ClientIdentityMerger.Merge` 逐字段合并；删除旧 `Headers` 字段。 |

| D17 | **StaticProvider 的唯一 D**：public `StaticProvider` 是唯一额外公共便利类型；若要求零额外公共面，执行时降 internal（测试/Faux 改走 ProviderFactory）。 |

## 3. Auth 公共形状

> 落点：`src/PiUnityAgent.Ai/Providers/Auth/`。以下类型替换现有 Auth 文件；名称采用 C# 惯用（`IAuthContext`），行为语义贴 pi/pi.net。

### 3.1 凭据

```csharp
public abstract record Credential;

public sealed record ApiKeyCredential(string? Key = null) : Credential
{
    /// <summary>provider-scoped env/config values, e.g. Cloudflare account id.</summary>
    public IReadOnlyDictionary<string, string>? Env { get; init; }

    public IReadOnlyDictionary<string, JsonNode?>? Extra { get; init; }

```

### 3.2 AuthContext / AuthResult / AuthCheck

```csharp
public interface IAuthContext
{
    Task<string?> EnvAsync(string name, CancellationToken cancellationToken = default);
    Task<bool> FileExistsAsync(string path, CancellationToken cancellationToken = default);
}

public sealed class DefaultAuthContext : IAuthContext
{
    // process env + File.Exists
}

public sealed record ModelAuth
{
    public string? ApiKey { get; init; }
    public IReadOnlyDictionary<string, string?>? Headers { get; init; }
    public string? BaseUrl { get; init; }
}

public sealed record AuthResult(
    ModelAuth Auth,
    IReadOnlyDictionary<string, string>? Env = null,
    string? Source = null);

public sealed record AuthCheck(AuthType Type, string? Source = null);

public sealed record AuthResolutionOverrides
{
    public string? ApiKey { get; init; }
    public IReadOnlyDictionary<string, string>? Env { get; init; }
    public long? MinOAuthValidityMs { get; init; }
    public CancellationToken Signal { get; init; }

```

**语义**：

- 未配置认证 = `AuthResult? == null`，不是 `AuthCheck(false)`。
- `AuthResult.Auth` 是请求时的最终载荷（apiKey/headers/baseUrl）；`Env` 是 provider-scoped env，最终与 request Env 合并（request 优先）。
- `AuthResolutionOverrides.ApiKey/Env/Signal` 参与解析；删除旧的 `Credential` override（pi 无此字段）。

### 3.3 凭据 store

```csharp
public interface CredentialStore
{
    Task<Credential?> ReadAsync(
        string providerId,
        AuthOperationOptions? options = null);

    Task<IReadOnlyList<CredentialInfo>> ListAsync(
        AuthOperationOptions? options = null);

    Task<Credential?> ModifyAsync(
        string providerId,
        Func<Credential?, Task<Credential?>> modify,
        AuthOperationOptions? options = null);

    Task DeleteAsync(
        string providerId,
        AuthOperationOptions? options = null);
}

public sealed record AuthOperationOptions
{
    public CancellationToken CancellationToken { get; init; }
}
```

- `ModifyAsync` 是唯一写路径；返回新凭据或 `null` 表示不变（不是删除；删除走 `DeleteAsync`），返回值是写后凭据。内存实现按 provider `SemaphoreSlim` 串行化；不能在 `await` 期间持普通 `lock`，也不得用 `GetAwaiter().GetResult()` 阻塞异步回调。
- 不保留 `GetAsync/SetAsync`（旧 S3 发明）；全部调用点改为 Read/Modify/Delete/List。
- 不做持久化文件实现（D7/S5）。
- `AuthOperationOptions` 以 `CancellationToken` 承载 pi 的 `signal`（A）；不再同时保留 options 与独立 ct 两个取消入口。

### 3.4 ProviderAuth / ApiKeyAuth / OAuthAuth

```csharp
public sealed record ProviderAuth
{

}

public sealed record ApiKeyResolveInput(

{
    public required string Name { get; init; }

    public Func<ApiKeyCheckInput, CancellationToken, Task<AuthCheck?>>? Check { get; init; }

    public required Func<ApiKeyResolveInput, CancellationToken, Task<AuthResult?>> Resolve { get; init; }
}

public sealed record OAuthAuth
{
    public required string Name { get; init; }
    public bool IsSubscription { get; init; }
```

### 3.5 交互类型

保留现有 `AuthPrompt`/`AuthEvent`/`AuthInfoLink`/`AuthInteraction`/`LoginOptions`，但：

- `ProviderAuthInteraction : AuthInteraction`（现在只是包装类）。
- `AuthPrompt` 保留 `CancellationToken`；`AuthEvent` 字段保持 pi 1:1。
- 不新增/删除公共字段，除非审计另有发现。

### 4.1 ModelsError

```csharp
public sealed class ModelsError : Exception
```

- `Models.Streaming.RequireProvider` 抛 `ModelsError(Provider, "Unknown provider: ...")`（审计后修复，向 pi `models.ts` 与 pi.net `Models.cs` 同时看齐），由 LazyStream 统一编码为终态 Error；`LogoutAsync` 按 pi `logout` 只删 store，未知 provider 是 no-op（不校验 provider 是否注册）。

- `Task.Run` 调度保持 pi.net 语义；不是首次消费才启动（已登记 B；不属于本次收口）。

### 4.6 Models 认证/可用性行为（API Key 路径）

本 spec **实现 API Key 路径**，OAuth 仍 C/D1：

1. `GetAuthAsync(providerId/model, overrides)`：
   - 先处理显式 `overrides.ApiKey`：仅当 provider 有 `ApiKey` 时，合成 `ApiKeyCredential`（带 `overrides.Env`）走 provider `Resolve`；结果直接返回（null 也是结果）。
   - 否则读 `CredentialStore`：stored OAuth → `OAuthAuth.ToAuth`（刷新/过期仍 D1）；stored API key → provider `Resolve`；stored 类型无匹配 → **null，不回落 ambient**。
   - 仅“无 stored”时走 ambient：provider `ApiKey.Resolve`；无 `ApiKey` → null。
   - 所有 provider/store 异常统一包 `ModelsError(Auth/OAuth)`；`GetAuth(model)` 在结果上合并 `model.Headers`。
   - 传入 `overrides.Signal` / `AuthOperationOptions.CancellationToken` 到 Resolve/Store；D12 一并解决取消传递。
   - 返回 `AuthResult`（`ModelAuth` + Env + Source）。
2. `Models.Stream/StreamSimple` factory 内：
   - 解析 auth（调用 `GetAuth(model, { apiKey, env, signal })`——请求级 `Env` 参与解析期 overlay，pi applyAuth 同款；确保 model 头已合并）；按 `AuthResult.Auth.ApiKey` 填 `options.ApiKey`（`options.ApiKey is null` 时；空串是显式值，胜过解析结果）；
   - 合并 `AuthResult.Auth.Headers` + request headers（null 抑制默认头）；
   - `AuthResult.Auth.BaseUrl` 覆盖 model.BaseUrl；
   - `AuthResult.Env` 与 request Env 合并（request 优先）；
   - `Identity` 用 `ClientIdentityMerger.Merge(_identity, options.Identity)`，不是 `??`；
   - 最后执行 `StreamOptions.TransformHeaders`（若提供），再交给 provider（provider 不感知）。
3. `GetAvailable*`：
   - 每个 provider 只调用一次 auth 检查（D12）：`CheckAuthAsync`；`ApiKeyAuth.Check` 存在时以 Check 结果为权威，缺失时才回退 `Resolve`。
   - 配置为 null → 不出现；
   - `IFilterableProvider.FilterAllModels` 非 null → 用它；null → chat 用 `FilterModels`，**保持原顺序**按 chat id 过滤，其他类别原样保留。
4. `CheckAuthAsync`：
   - provider 不存在 / 未配置 → null；
   - stored OAuth 且 provider 有 OAuth → `AuthCheck(AuthType.OAuth, "OAuth")`；
   - stored API key / ambient → `AuthCheck(AuthType.ApiKey, source)`；不再有 `Configured` bool。
5. `LoginAsync` 仍 D1/S5 stub；`LogoutAsync` 只 `CredentialStore.DeleteAsync`（不调 provider OAuth.Logout），存储失败包 `ModelsError(Auth)`。
6. `RefreshAsync` 仍 D2/S4 空结果；`ModelsStore` 形状已存在。
7. 无认证的 provider 不再合法；Faux 提供 keyless `ApiKeyAuth`，其 Resolve 返回 `AuthResult(new ModelAuth())`，Source `"Faux"`。

## 10. 风险

1. **破坏面大**：Auth 全面换形，Models/Faux/测试全部 breaking；按阶段保持可编译。
2. **Auth 行为越界**：API Key 实现要克制，OAuth/刷新/目录仍后置；不能在 shape 任务里写完 S5。
3. **ProviderFactory 复杂度**：api-map/Images/Classifiers 分派需测试；不要在 S3 实现真实 provider。
4. **ModelsStore**：形状对齐但 D2 行为后置；避免用旧 Data/UpdatedAt 兼容。
5. **TransformHeaders**：C# 无 intersection，放 StreamOptions 需文档明确 Models-only；provider 应忽略。
6. **IProvider.Auth 非空**：Faux/测试 provider 都要给 keyless auth；旧 null 测试删除。
7. **重审计**：完成后必须由新独立 subagent 审计；不能沿用原审计者结论。
8. **Identity 破坏面**：`ClientIdentity` 从字符串/Headers 改为 UserAgentMode/Attribution/Version；所有测试与 Faux 调用点同步改。
9. **观察者顺序**：按 pi 后置 observer；若为了 telemetry span 收尾改回 pi.net 前置，必须重新登记 B，不能默认沿用。
