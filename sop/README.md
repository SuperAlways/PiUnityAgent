## 约定

- 一篇 SOP 只解决一类可复现的操作问题；
- 必须包含：现象、根因、诊断命令、修复步骤、验证方式、回滚、常见坑；
- 实测事实（端口、commit、日期）写死在文档里，不写"大概/可能"；
- 后续新增 SOP 在此登记。
