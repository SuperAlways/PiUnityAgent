## 三、怎么用参考索引

1. **每个阶段先读原版源码**，再读教学书；书只用来补"为什么"和"整体图"。
2. **主要参考读 1 篇，次要参考按需读**；不要一次读完整本书。
3. 教学书基于旧版本：路径/API 可能过时，**以 v1.5.0 源码为准**。
4. 每篇教学文档末尾加"延伸阅读"，只放 1–3 个最相关的章节。
5. 读完一节，做一个小练习；写不出练习，说明没懂。

## 四、暂不读 / 暂不做

| 内容 | 原因 |
|---|---|
| coding-agent CLI、TUI、slash commands、themes、keybindings | 游戏 mod 不用终端 UI |
| bash/read/write/edit/grep/find 工具章节 | 编码专用；我们的工具是游戏查询/动作 |
| MCP、codemode、durable、env | 后续可选，不是 M1 |
| pi-bluebook 的安装/更新/卸载、VPS、Windows 安装 | 与移植无关 |
| Pi.NET 的 OAuth/图片/分类/42 家 provider | 不在裁剪范围 |
| pi-book 的 web/gateway/书籍引擎章节 | 与本项目无关 |
