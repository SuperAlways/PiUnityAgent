> **维护**：每进入目标阶段，先读本表对应行；完成后更新状态并写入该阶段 spec/plan。
> **最后更新**：2026-11-07（S3 返工 v2 / B 通讯端口）

## 通讯层集成（非后置登记）

S3 返工 v2 定义 `FetchFunction`/`FetchRequest`/`FetchOptions`/`IFetchResponse`/`FetchException`/`TransportKind` 的公共形状（B 方案，见 `docs/07-通讯层集成契约.md`）。以下行为不属于 S3 后置，按阶段实施：

| 目标阶段 | 内容 |
|---|---|
| S4 | provider 用 Fetch 端口构造请求、映射错误/超时/重试/认证 header；SSE 解析与聚合 |
| S4 / S13 | `UnityLlmTransportFetch` 适配器（`IStreamingHttpTransport` → Fetch 端口）+ 契约测试 |
| S4 / Hosts.Net8 | `HttpClientFetch`（`ResponseHeadersRead` + per-call timeout） |
| S5+ | 独立 WebSocket 端口（`transport=websocket` 的 provider 使用） |
| 2B/后续 | 图片/分类/Deferred 的 Fetch 用法 |

## 代码标注约定

- 流式入口的后置失败：编码为终态 `Error`，不抛；
- 非流式能力的后置失败：`throw new NotSupportedException("Deferred to Sx: <能力> (Dn)");`
- 字段/类型已存在但行为未接：`// TODO(Sx, Dn): <说明>`；
- 评审门禁：`grep -R "TODO(S\|Deferred to S" src/`，每一条必须能在本表找到 Dn。
